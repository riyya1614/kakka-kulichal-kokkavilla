# kakka-kulichal-kokkavilla
What happens when a crow tries to become a crane? Explore this fun interactive game based on the Malayalam proverb “കാക്ക കുളിച്ചാൽ കൊക്കാവില്ല” and see what happens when a crow tries to change its appearance. Clean the crow, watch it transform through different stages, and discover whether a simple bath can really make a crow a crane!
