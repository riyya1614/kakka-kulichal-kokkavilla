# 🐦 Kakka Kulichal Kokkavilla

### *What happens when a crow tries to become a crane?*

**Kakka Kulichal Kokkavilla** is a fun and interactive web game inspired by the famous Malayalam proverb **“കാക്ക കുളിച്ചാൽ കൊക്കാവില്ല”**.

The game brings this traditional saying into a playful digital experience. Players help a dirty crow clean itself through different stages and discover whether simply getting clean can really change a crow into a crane.

---

## 📌 Project Status

**Status: 🟡 In Development**

The core game is functional, including the cleaning stages, interactions, audio feedback, and visual elements.

The project is still being improved with plans for a more realistic background, enhanced voice/audio, animations, and overall visual polish.

## 🎮 About the Game

The game starts with a dirty crow.

The player interacts with the crow to clean it. As the player continues cleaning, the crow goes through different cleanliness stages until it becomes fully clean.

But there is one question:

> **Can a crow become a crane just by taking a bath?**

The game is a humorous interpretation of the Malayalam proverb **“കാക്ക കുളിച്ചാൽ കൊക്കാവില്ല”**, which reminds us that changing one's appearance does not necessarily change one's true nature.

## 🕹️ How to Play

1. Start the game.
2. A dirty crow appears on the screen.
3. Click the crow to begin cleaning.
4. Continue interacting with the crow.
5. Watch the crow become cleaner through different stages.
6. Listen to the audio feedback during the cleaning process.
7. Complete the cleaning and see the final result.

### 🎯 Goal

**Clean the crow completely and find out if a crow can really become a crane!**

## 💡 Inspiration

The project is based on the Malayalam proverb:

### **“കാക്ക കുളിച്ചാൽ കൊക്കാവില്ല”**

**Meaning:**
Even if a crow takes a bath and becomes clean, it does not become a crane.

The game turns this familiar proverb into an interactive experience while combining **Malayalam culture, humor, storytelling, and web technology**.

## 🎨 Game Concept

```text
        🐦
     Dirty Crow
          ↓
      🧼 Clean
          ↓
   Cleaning Stage 1
          ↓
   Cleaning Stage 2
          ↓
   Cleaning Stage 3
          ↓
     ✨ Fully Clean
          ↓
   🐦 Still a Crow!
```

The final result represents the meaning behind the proverb: **appearance can change, but identity does not simply change with it.**
