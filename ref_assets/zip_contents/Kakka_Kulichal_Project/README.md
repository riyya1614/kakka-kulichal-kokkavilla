# കാക്ക കുളിച്ചാൽ കൊക്കാവില്ല 🐦🛁

## Run it (2 ways — pick ONE)

### Option A — Live Server (frontend only)
1. Open this folder in VS Code
2. Install the "Live Server" extension
3. Right-click `index.html` → "Open with Live Server"

### Option B — With backend (scores saved)
1. Open Terminal in this folder
2. Run: `node backend/server.js`  (no npm install needed!)
3. Open http://localhost:3000

## Add YOUR assets (optional)
The game already works with built-in SVG crow/crane.
To use your own images & voice:

1. Voice: save your recording as `assets/audio/poyi-kulikeda.mp3`
2. Crow image: replace the crow SVG (search `CROW_SVG` in `script.js`)
   or drop `assets/crow.png` and swap the `<img>` in
3. Crane image: drop `assets/crane.png`

## How to play
1. Start → crow wanders, sees crane, gets insecure 😭
2. Click "ഞാനും സുന്ദരിയാവും!"
3. Pick 🧼 / 🚿 / 🪥 and scrub the crow (click or drag) until 100% clean
4. Faster bath = higher score
5. Enjoy being congratulated on still being a crow 💀
